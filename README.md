# WEB DEV TASK BOARD

This project is a Kanban-style task management app built as a full-stack front-end portfolio project. Demonstrates real-time data, firebase authentication, drag & drop, animations, and a component library, built on the way to a juniour developer role.

Live: (https://web-dev-task-board.vercel.app)

## TECH STACK

| Layer | Technology |
|---|---|
| Framework | React 19 + TypeScript |
| Build Tool | Vite |
| State Management | Redux Toolkit |
| Routing | React Router v7 |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion |
| Drag and Drop | dnd-kit |
| Auth | Firebase Authentication (email/password |
| Database | Firestore (real-time)
